Privacy Policy

AI Student Profile Creator • Last Updated: November 2026

1. Introduction

This Privacy Policy describes how the AI Student Profile Creator Google Workspace Add-on ("the Add-on", "we", "us", or "our") handles data when educators and institutions install and use the Add-on within Google Workspace (Google Docs™, Google Sheets™, or Google Forms™).

We are committed to maintaining the highest standards of data privacy and protecting the confidentiality of educator and student information in compliance with relevant educational privacy laws, including the Family Educational Rights and Privacy Act (FERPA) and the Children's Online Privacy Protection Act (COPPA).

2. Information We Access and Process

The Add-on operates directly within your Google Workspace environment.

Data Category Description & Processing Details Storage Location
Survey & Diagnostic Inputs Data provided via Google Forms™ or Google Sheets™ (e.g., student diagnostic survey responses, learning preferences, assessment scores) that you explicitly choose to analyze. Local Workspace Session
Generated Profile Outputs Structured learner profile summaries, activity tiers, and differentiation tags generated by the Add-on. User's Google Doc / Sheet
Google User & Auth Data Basic user authentication details provided via standard Google OAuth 2.0 authorization to verify access permissions. Temporary Session Token

Data Persistence Notice

We do not store, host, sell, or commercialize your student data or user content on external private servers. All data processing occurs strictly within your active Google Workspace session.

3. Data Protection & Educational Privacy

  • No Data Sales or Advertising: We do not sell user data, student data, or metadata to third parties, nor do we use student data to target advertising.
  • Educational Compliance: The Add-on is designed to respect family and student privacy guidelines (FERPA and COPPA). All student diagnostic data remains under the direct ownership and control of the installing educator or educational institution.

4. Google Workspace API Limits & Policy Compliance

Use of information received from Google APIs will adhere to the Google Workspace API User Data Policy, including the Limited Use requirements.

  • The Add-on requests only the minimum necessary Google OAuth permissions (scopes) strictly required to read diagnostic input sheets/documents and generate profile outputs.
  • Google Workspace user data is never used to train generalized artificial intelligence or machine learning models.

Google OAuth Permissions Breakdown

Google OAuth Scope Plain-Language Explanation & Purpose
.../auth/spreadsheets Creates and formats profile tabs and writes summaries in Google Sheets™.
.../auth/classroom.* Reads course rosters and student names/emails from Google Classroom™ to populate profiles.
.../auth/drive Accesses or exports user-selected profile documents/sheets.
.../auth/documents Generates long-form student profile summaries upon request in Google Docs™.
.../auth/forms Builds observation forms linked back to the spreadsheet.
.../auth/script.external_request Transmits pseudonymized prompt payloads to Gemini API endpoints via HTTPS.
.../auth/script.container.ui Renders the interactive sidebar and setup wizard.
.../auth/cloud-platform Authenticates API requests directly using your account token without external keys.

5. Third-Party AI Service Integration

If the Add-on connects to external AI services (e.g., OpenAI API or Google Gemini API) to generate student profile summaries:

  • Data sent to API endpoints is used solely to generate the requested profile outputs for your active session.
  • Zero Data Retention (ZDR) or strict non-training API agreements are enforced so that API providers do not use your inputs or student data to train public models.

6. Data Retention and Deletion

Because your data is stored directly inside your own Google Docs™, Sheets™, or Google Drive™ files:

  • You retain complete ownership and control over all data.
  • Deleting your Google Doc™, Google Sheet™, or uninstalling the Add-on immediately revokes access and removes local session data.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes in functionality or legal requirements. Any updates will be posted to this document with a revised "Last Updated" date.
